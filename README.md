# okaeri-syllabus-in-hokudai

北海道大学の学務Webシステムにおけるシラバス検索および一覧画面を、直感的に選びやすく、かつモダンで美しいデザインに刷新するChrome拡張機能です。

既存のページが抱えるレイアウトの見づらさや検索の不便さを解消し、スマートなシラバス閲覧環境を提供します。

## 📌 主な機能と特徴

### 検索入力画面
- **直感的なチップUI**: 開講年度、課程区分、開講学部、対象年次、開講曜日・時限などを、セレクトボックスではなくワンクリックのチップ形式で選択可能。
- **一括学部選択**: 課程区分を切り替えても、すべての学部・研究科を「学部・研究科を選択」として一括でスッキリ表示。
- **検索項目の最適化**: 重要な「全文検索」をキーワードセクションの教員名直下に配置し、利用頻度の低い補助項目は「詳しく検索」アコーディオン内へ格納。

### 検索結果画面
- **快適な一覧レイアウト**: カラム幅の比率を再配分し、最も重要な「科目名」の横幅を適正化（スッキリした幅に調整）。右端の不要な余白やスペースをカットし、画面内に情報が美しく収まります。
- **完全なページネーション連携**: 検索結果が30件を超えた場合でも、下部にモダンなページングボタンおよび「次のページへ >」ボタンを自動生成。

### 詳細画面
- **iNAZO連携**: 検索結果から、科目名や教員名でワンクリックで iNAZO 検索へジャンプ可能。
- **表示の最適化**: シラバスの表示を適切な大きさにすることで視認性を向上。

### 設定ポップアップ
- **拡張機能のオンオフ**: ポップアップ内のトグルボタンで、直感的に拡張機能の有効・無効を切り替え可能。


## ⚠️ シラバス閲覧に関する留意点

本拡張機能は、大学公式の学務Webシステムが生成するHTMLデータをブラウザ側でリアルタイムに取得・解析してUIを再構築しています。そのため、以下の点にご留意ください。

1. **シラバスデータの不具合について**: 
   表示される講義内容、教員名、曜日時限等のシラバスデータそのものは、大学のサーバーから返された生データをそのまま引き継いでいます。万が一シラバスの記載内容自体に不具合や誤りがあると思われる場合は、本拡張機能のバグではなく、大学公式システム側の登録データに起因する可能性があります。
   また、本機能の不具合により本来表示されるべきデータが表示されない場合もあるかもしれません。
2. **公式情報との差異**:
   時間割の変更や最新の公示については、必ず大学公式の学務Webシステム上の掲示板、または所属学部の事務部からの連絡を第一正本として確認してください。

## 🛠️ 技術スタック

- **Framework**: [Plasmo](https://www.plasmo.com/) (v0.90.5) - 堅牢なブラウザ拡張機能開発フレームワーク
- **Library**: React, TypeScript
- **Styling**: 純粋な CSS (CSS Paged Media / Component Styles)
- **Build Tool**: Parcel (Plasmo 組み込みエンジン)
- **Font/UI Accents**: Gen Interface JP (CDN 経由)

### 💡 技術的なブレイクスルー (Chromeセキュリティ制限の完全回避)
学務Web（ASP.NET）の仕様上、元のページングや戻るリンクには `javascript:__doPostBack(...)` などのインラインスクリプトが直接埋め込まれています。これらを拡張機能から直接叩くと、Chrome の強力なセキュリティポリシーである **CSP (Content Security Policy) 違反** としてブラウザにブロックされてしまいます。

本拡張機能では、この問題を解決するため、`javascript:` プロトコルを一切経由せず、**「裏側の隠しフィールド（`__EVENTTARGET`, `__EVENTARGUMENT`）の値をネイティブ操作で書き換え、ブラウザ標準の機能としてフォームを直接 `submit()` する」** というロジックを採用しています。これにより、ブラウザのセキュリティブロックを100%安全に回避し、確実なページ遷移と検索実行を達成しています。
